# Akshada B — Portfolio

🔗 **Live Portfolio:**https://akshada.vercel.app/

A modern portfolio website built with React and Vite to showcase my work in clinical AI, machine learning, and full-stack development.

## Features

* Modern black-and-white UI with glassmorphism styling
* Fully responsive across desktop, tablet, and mobile
* Project showcase featuring AI, ML, and development work
* Smooth animations and interactive design

## Tech Stack

* React
* Vite
* CSS
* react-icons
* lucide-react

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`
